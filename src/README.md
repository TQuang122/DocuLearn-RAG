Core Source Files

The src/ directory contains the following core modules:

* config.py — Manages application configuration.
* schemas.py — Defines data models and schemas.
* indexing.py — Handles document loading and indexing.
* store.py — Manages vector storage.
* rag.py — Implements the RAG retrieval pipeline.
* learning.py — Generates learning materials.
* llm.py — Handles interactions with the large language model.
* filters.py — Applies metadata-based filtering.
* export.py — Exports generated results.
